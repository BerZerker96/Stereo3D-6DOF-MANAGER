SuperDepth3D is the safety net — if nothing else covers your game’s API, it will. geo-11 gives the best image but only on DX11. Old game on DX7/8/9? Either use wiz3D / 3DVision4All directly, or convert it to DX11 with dgVoodoo2 and then use geo-11 or Geo3D.

SuperDepth3D every API

Builds a stereo pair from the depth buffer. Runs on almost anything; can’t show what the camera never drew.

Settings: ReShade overlay — Space. Already switched on.

Better depth

  • Depth_Map first — fixes flat or inside-out.
  • Reversed? DEPTH_INPUT_IS_REVERSED. Upside-down? ..._IS_UPSIDE_DOWN.
  • Depth_Adjustment = strength. Raise till edges strain, back off.
  • Zero_Parallax_Distance = screen plane. Lower pops out, higher sinks in.
  • Turn off in-game AO, DOF, motion blur — they pollute depth.
  • Disable MSAA if depth access fails.
  • Flat weapon is normal — nudge Perspective, not depth.
  • Eye_Swap if near looks far.

VR export

SuperVrExport / GeoVrExport share a full-res SBS frame straight to Katanga or VRScreenCap. Pick the VR add-on output — the app wires it up.

Same 3Dmigoto lineage, so the keys are identical.

geo-11 DX11 only

Renders the scene twice — real geometry per eye. Best quality where supported.

  • Defaults: dm_separation / dm_convergence in d3dxdm.ini.
  • dm_auto_convergence is on by default.
  • hunting=1 in d3dx.ini shows live convergence.
  • Per-game fixes add F1–F8 presets — see its HelixMod page.

Geo3D DX9 → DX12

Flugan’s geometric 3D, hosted inside ReShade. Bundled Legacy build is what one-click uses.

  • Installed with 3DToElse on, in = Frame Sequential, out = SBS.
  • StereoSeparation / StereoConvergence are the dials.
  • Output + shader settings: ReShade overlay (Space).

3DVision4All DX9 / DX10 + legacy

Runs 3D Vision titles on any 3D display. NVIDIA GPU required.

⚠ Run EnableWindowed3D.exe as admin once per game folder, or stereo never activates. The app offers to do it.

dgVoodoo2 DX7–10 → DX11

A translator, not a 3D mod. Makes an old game look like DX11 so geo-11 / ReShade / Geo3D can run. Install it first.

Fine-tuning

  • Tracker → UDP 127.0.0.1:4242.
  • Start sensitivity low; raise till a comfy turn covers the view.
  • Set limits before sensitivity — stops clipping through the model.
  • Positional lean: keep near 1:1. Scaling it up causes sickness.
  • Re-centre sitting how you actually sit.
  • Smoothing trades lag for calm — a little kills jitter.
  • Turn off head-bob, camera shake, cinematic FOV.
  • Not loading? It’s the loader — and its bitness.
Stacking

3D mod first, then 6DOF. Slot clashes are refused by name — 3DVision4All is moved aside automatically.
